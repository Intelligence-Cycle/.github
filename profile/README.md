# Neul Space

We build **TIC — The Intelligence Cycle**: a replayable, text-first
investigative game where you solve cases by interviewing suspects,
collecting evidence, and reasoning through contradictions — modelled on
the real-world intelligence cycle.

TIC runs on **Gridlock**, our investigative game engine.
